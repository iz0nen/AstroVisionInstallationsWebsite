# Astro Vision Installations Website

## Run locally
npm install
npm run dev

## Build for Vercel
npm run build

## Logos
The logos are stored in `public/assets/` and referenced as:
- `/assets/astro-vision-main-logo.jpg`
- `/assets/astro-vision-secondary-logo.png`

## Quote form
The quote form is currently front-end only. For Vercel, connect it with one of these:
- Formspree (fastest)
- Resend + Vercel Serverless Function
- EmailJS
